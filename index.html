Como funciona

Cada caso tem as próprias tabelas, então os três cabem no mesmo projeto do Supabase. O progresso de cada caso fica salvo no navegador, e pode ser guardado na nuvem com uma conta, dentro de qualquer caso, pelo botão ☁ no topo.

Inspirado no SQL Murder Mystery do Knight Lab. Personagens e dados são fictícios.
